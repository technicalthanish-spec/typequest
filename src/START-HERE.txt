TYPEQUEST — FINAL ONLINE VERSION

This build is ready for GitHub + Vercel deployment.

1. Upload the project files to GitHub (do NOT upload .env).
2. Import the GitHub repo into Vercel.
3. Add these Vercel Environment Variables:
   VITE_SUPABASE_URL
   VITE_SUPABASE_ANON_KEY
4. Deploy.
5. In Supabase Authentication → URL Configuration, set your Vercel site URL as the Site URL and add it to Redirect URLs if needed.
6. Test account creation/login, progress sync, reset, and logout.

Database:
- Supabase Auth stores the account/email and securely handles passwords.
- public.game_states stores each user's TypeQuest progress.
- IndexedDB stores a local browser cache.
- Row Level Security restricts game state access to the signed-in user.
